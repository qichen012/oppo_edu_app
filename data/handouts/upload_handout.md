本讲义系统地介绍了信息论中的核心概念，包括自信息、互信息、熵及其变种的定义、性质和应用。通过公式推导和性质分析，帮助学生理解信息度量的数学基础及其在通信和优化中的应用。

## 1. 信息度量的基本概念

信息度量体系分为单个事件的信息度量和事件集的平均信息度量。单个事件的信息度量包括自信息、条件自信息、联合自信息、互信息和条件互信息。事件集的平均信息度量包括熵、条件熵、联合熵、平均互信息和平均条件互信息。这些概念为信息论的核心内容，描述了不确定性和信息量的定量关系。

### 核心概念
**自信息**
- 定义：描述单个事件发生时带来的信息量，定义为 I(x) = -log p(x)。
- 公式：$$I(x) = -\log p(x)$$
- 示例：若某事件发生概率为 0.5，则其自信息为 I(x) = -\log(0.5) = 1 比特。

**互信息**
- 定义：描述两个事件之间的统计关联程度，定义为 I(x;y) = \log [p(x|y) / p(x)]。
- 公式：$$I(x;y) = \log \frac{p(x|y)}{p(x)}$$
- 示例：若事件 x 和 y 独立，则 I(x;y) = 0。

> 📌 **学习提示**：掌握自信息和互信息的定义及其物理意义是理解信息论的基础。

## 2. 熵及其变种

熵是信息论中衡量不确定性的核心指标，定义为信源输出符号的自信息的期望值。条件熵描述在已知条件下剩余的不确定性，联合熵衡量多个随机变量整体的不确定性。相对熵（信息散度）和交叉熵则用于衡量概率分布之间的差异。

### 核心概念
**熵**
- 定义：信源输出符号的不确定性平均值，定义为 H(X) = -Σ p(x) log p(x)。
- 公式：$$H(X) = -\sum p(x) \log p(x)$$
- 示例：若信源有两个等概率事件，则 H(X) = -[0.5 \log 0.5 + 0.5 \log 0.5] = 1 比特。

**条件熵**
- 定义：在已知一个随机变量的情况下，另一个随机变量的平均不确定性。
- 公式：$$H(Y|X) = -\sum p(x,y) \log p(y|x)$$
- 示例：若 X 和 Y 完全独立，则 H(Y|X) = H(Y)。

**相对熵**
- 定义：两个概率分布之间的差异程度，定义为 D(P‖Q) = Σ P(x) log [P(x) / Q(x)]。
- 公式：$$D(P\|Q) = \sum P(x) \log \frac{P(x)}{Q(x)}$$
- 示例：若 P 和 Q 完全一致，则 D(P‖Q) = 0。

> 📌 **学习提示**：注意熵的链式分解公式及其在信息处理中的应用。

## 3. 平均互信息与条件互信息

平均互信息描述两个随机变量之间的统计关联程度，是互信息的期望值。条件互信息则是在已知第三个变量的条件下，两个变量之间的额外信息增益。它们在通信系统中用于量化信息传输效率。

### 核心概念
**平均互信息**
- 定义：两个随机变量之间的平均信息共享量，定义为 I(X;Y) = Σ p(x,y) log [p(x,y) / (p(x)p(y))]。
- 公式：$$I(X;Y) = \sum p(x,y) \log \frac{p(x,y)}{p(x)p(y)}$$
- 示例：在通信中，接收端收到的关于发送端消息的平均信息量即为平均互信息。

**条件互信息**
- 定义：在已知第三个变量的条件下，两个随机变量之间的互信息。
- 公式：$$I(X;Y|Z) = \sum p(x,y,z) \log \frac{p(x|y,z)}{p(x|z)}$$
- 示例：若 X 和 Y 在给定 Z 的条件下独立，则 I(X;Y|Z) = 0。

> 📌 **学习提示**：条件互信息的非负性和链式分解是重要的性质，需重点掌握。

## 4. 信息论中的凸性与极值性质

信息论中的熵和互信息具有重要的凸性和极值性质。例如，熵是概率分布的上凸函数，最大熵出现在等概率分布时。凸性和极值性质为优化问题提供了理论基础。

### 核心概念
**最大熵定理**
- 定义：对于 n 元离散信源，熵的最大值为 log n，当且仅当所有事件等概率时达到最大值。
- 公式：$$H(X) \leq \log n$$
- 示例：若信源有 4 个等概率事件，则最大熵为 log 4 = 2 比特。

**凸性**
- 定义：熵是概率分布的严格上凸函数，混合分布的熵大于各成分熵的加权平均。
- 示例：在优化问题中，凸性保证了唯一最优解的存在性。

> 📌 **学习提示**：凸性和极值性质是信息论与优化理论结合的桥梁。
